# Myra-CNA notices

Myra-CNA is an independent, unofficial C++23 port of the Myra UI library for
CNA. It is not affiliated with, endorsed by, or an official project of the
Myra Team.

The intended Myra source baseline is
[`MyraUI/Myra`](https://github.com/MyraUI/Myra) revision
`0d79b939310bfe1d00b21803fe15e291caf60aa1`.

No upstream Myra source code or asset has been ported into this repository at
the time of this notice's creation. Once a translation is added, its header and
`UPSTREAM_MANIFEST.md` entry identify the exact source file and its applicable
notices. The complete licence texts for Myra and other direct upstream lineages
are in `THIRD_PARTY_NOTICES.md`.

The Myra name is used only to identify the upstream library being ported.
