# Original wallpaper texture

`wallpaper-v1.png` was generated specifically for cna-backrooms using the built-in OpenAI image generation tool on 2026-09-28. No reference image was supplied as an input. The downloaded Backrooms photograph was used only for separate visual QA and is not a game asset.

The original generated PNG is retained without offline edits. CNA resizes it to 1024 by 1024 at startup and the game builds its mip chain. The intended texture footprint is 1.25 metres square. A procedural fallback remains available if the PNG cannot be loaded.

Primary request: create an original faded late-1960s/1970s commercial office wallpaper. The entire image is only the flat wallpaper surface, viewed perfectly front-on orthographic. Small restrained elongated leaf-and-lozenge ornaments with fine vertical stem/pinstripe connections, ordered in approximately eight columns and eight rows across the square. Muted olive/tan ink on pale aged cream-yellow paper, roughly RGB 211,200,145 background. The motif should have visible but modest contrast, delicate slightly worn printing, fine paper fibers and very faint tiny aging speckles. It should look mundane and dated, not luxurious. All four edges repeat seamlessly with one another. Even neutral illumination, no shadows, no perspective, no vignette, no highlights, no directional lighting or large stains baked in. No walls, floors, objects, labels, borders, text, watermarks, or logos. Produce one square 1024 by 1024 bitmap texture.
